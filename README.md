# CallEnglish — AI English Speaking Tutor

**Live Website**: [https://eng-alm.pages.dev/](https://eng-alm.pages.dev/)

An AI-powered web application that simulates phone calls for English speaking practice.

## Features

- Real-time voice conversation with AI tutors
- Speech recognition and text-to-speech (Web Speech API)
- Listening mode for language learners
- Multi-accent support (American, British, Australian)
- Scenario-based learning (Daily, Business, Travel)
- Grammar correction and feedback
- User authentication and conversation history

## Tech Stack

- **Frontend**: React 19 + TypeScript + Vite 8
- **Backend**: Hono (Cloudflare Workers)
- **Database**: Cloudflare D1 (SQLite)
- **AI**: Qwen 3.5 Plus
- **Speech**: Web Speech API

## Quick Start

```bash
npm install
npm run dev
```
